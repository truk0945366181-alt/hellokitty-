# ระบบแจ้งเตือนคนแปลกหน้าหน้าห้องพัก — Prototype

Prototype สำหรับงาน "Design an MVP" — ตรวจจับใบหน้าจากภาพ/กล้อง เปรียบเทียบกับรายชื่อผู้พักอาศัย (Whitelist)
และส่งแจ้งเตือนไปยังแอดมิน/เจ้าของหอผ่าน Telegram เมื่อพบใบหน้าที่ไม่รู้จัก

> Prototype นี้มีไว้เพื่อสาธิต **Core Experience** ของ MVP เท่านั้น ไม่ใช่ระบบ Production ที่สมบูรณ์
> ตามหลักการในเอกสารงาน "ไม่จำเป็นต้องมี Dataset จริง — ใช้ Synthetic/Simulated Data ในการออกแบบและทดสอบได้"

## เทคโนโลยีที่ใช้ และเหตุผล

| ส่วนประกอบ | เทคโนโลยี | เหตุผลที่เลือก |
|---|---|---|
| ตรวจจับใบหน้า (Face Detection) | OpenCV Haar Cascade | เบา รันได้บนเครื่องทั่วไป ไม่ต้องใช้ GPU ไม่ต้องดาวน์โหลดโมเดลใหญ่ |
| จดจำใบหน้า (Face Recognition) | LBPH (Local Binary Patterns Histograms) | เป็น rule-based/statistical model ที่อธิบายผลลัพธ์ได้ ไม่ใช่ black-box แบบ deep learning เหมาะกับ MVP ที่ต้องอธิบายการตัดสินใจได้ |
| การแจ้งเตือน | Telegram Bot API | ตั้งค่าง่าย ฟรี ไม่ต้องมีบัญชีธุรกิจ (ทางเลือกแทน LINE Notify ซึ่ง**ถูกยกเลิกบริการไปแล้วตั้งแต่ 31 มี.ค. 2025** — ผู้ที่ต้องการใช้ LINE ต้องเปลี่ยนไปใช้ LINE Messaging API ผ่าน LINE Official Account แทน ซึ่งซับซ้อนกว่า) |
| หน้าจอใช้งาน (UI) | Streamlit | สร้าง UI แบบโต้ตอบได้เร็ว เหมาะกับการทำ Prototype ในเวลาจำกัด |
| บันทึกประวัติ | CSV ผ่าน pandas | เพียงพอสำหรับ Prototype ไม่ต้องตั้งค่าฐานข้อมูลเพิ่ม |

## วิธีติดตั้งและรัน

```bash
# 1. ติดตั้งไลบรารีที่ต้องใช้
pip install -r requirements.txt

# 2. รันแอป
streamlit run app.py
```

จากนั้นเปิดเบราว์เซอร์ที่ระบบแจ้งไว้ (ปกติคือ http://localhost:8501)

## วิธีใช้งาน

1. **แท็บ "ลงทะเบียนผู้พักอาศัย"** — อัปโหลดภาพใบหน้าของผู้พักอาศัย (แนะนำ 3-5 ภาพต่อคน มุมต่าง ๆ) ระบบจะเทรนโมเดลใหม่ให้อัตโนมัติ
2. **แท็บ "ทดสอบตรวจจับ"** — อัปโหลดภาพทดสอบ หรือถ่ายภาพจากกล้องเว็บแคม ระบบจะตรวจจับใบหน้าและบอกว่า "รู้จัก" (กรอบเขียว) หรือ "ไม่รู้จัก" (กรอบแดง) หากพบคนแปลกหน้า สามารถกดส่งแจ้งเตือนไป Telegram ได้ทันที
3. **แท็บ "ประวัติการแจ้งเตือน"** — ดูสถิติและประวัติเหตุการณ์ทั้งหมดที่ระบบบันทึกไว้

## การตั้งค่า Telegram Bot (สำหรับการแจ้งเตือนจริง)

1. เปิด Telegram ค้นหา **BotFather** พิมพ์ `/newbot` แล้วทำตามขั้นตอน จะได้ **Bot Token**
2. ส่งข้อความอะไรก็ได้หาบอทของตัวเอง 1 ครั้ง
3. เปิดลิงก์ `https://api.telegram.org/bot<TOKEN>/getUpdates` ในเบราว์เซอร์ เพื่อดูค่า **chat id** ของตัวเอง
4. นำ Token และ Chat ID ไปกรอกในแถบด้านซ้าย (Sidebar) ของแอป

หากไม่ตั้งค่า Telegram ระบบยังคงทำงานได้ปกติ (ตรวจจับ + บันทึก log) เพียงแต่จะไม่มีการส่งข้อความออกจริง

## หมายเหตุการแก้ปัญหา (Troubleshooting)

**ถ้าเจอ error แบบนี้:**
```
cv2.error: ... !empty() in function 'cv::CascadeClassifier::detectMultiScale'
```
แปลว่าโปรแกรมหาไฟล์ตรวจจับใบหน้า (haarcascade) ไม่เจอ — สาเหตุที่พบบ่อยบน Windows คือโฟลเดอร์ติดตั้ง OpenCV
อยู่ใน path ที่มีอักษรไทยหรือมีปัญหาการติดตั้งไม่สมบูรณ์

**วิธีแก้ในโปรเจกต์นี้:** ไฟล์ `assets/haarcascade_frontalface_default.xml` ถูกแนบมาในโปรเจกต์แล้ว
และโค้ดถูกปรับให้โหลดไฟล์นี้จากตำแหน่งของโปรเจกต์เองโดยตรง (ไม่พึ่งพา path ของ OpenCV ในเครื่อง)
**อย่าลบหรือย้ายโฟลเดอร์ `assets` ออกจากโปรเจกต์**

## ข้อจำกัดที่ทราบอยู่แล้ว (สำหรับ Prototype นี้)

- ใช้ Haar Cascade ซึ่งแม่นยำน้อยกว่าโมเดล Deep Learning รุ่นใหม่ในสภาพแสงน้อยหรือใบหน้าเอียงมาก — ใน MVP ถัดไปอาจพิจารณาเปลี่ยนไปใช้โมเดลที่แม่นยำกว่า เช่น MTCNN หรือ RetinaFace
- ยังไม่รองรับวิดีโอสตรีมแบบต่อเนื่องจากกล้อง IP Camera โดยตรง — เวอร์ชันนี้รับเฉพาะภาพนิ่งหรือภาพจากเว็บแคม
- ไม่มีระบบยืนยันตัวตน/สิทธิ์การเข้าถึงหน้าแอป (Authentication) — ในระบบจริงต้องเพิ่มการล็อกอินสำหรับแอดมินเท่านั้น
- ภาพใบหน้าทั้งหมดถูกเก็บในเครื่อง (local) เท่านั้น — การใช้งานจริงต้องมีนโยบายการเก็บ/ลบข้อมูลใบหน้าที่ชัดเจน และขอความยินยอมจากผู้พักอาศัยก่อนเสมอ

## โครงสร้างไฟล์

```
prototype/
├── app.py            # หน้าจอหลัก (Streamlit UI)
├── face_engine.py     # แกนตรวจจับ+จดจำใบหน้า (Detection + Recognition)
├── alert.py           # ส่งแจ้งเตือนผ่าน Telegram
├── event_log.py        # บันทึก/อ่านประวัติเหตุการณ์
├── requirements.txt
├── README.md
├── assets/
│   └── haarcascade_frontalface_default.xml   # ไฟล์โมเดลตรวจจับใบหน้า (ห้ามลบ/ย้าย)
└── data/
    ├── whitelist/     # ภาพใบหน้าผู้พักอาศัยที่ลงทะเบียน (แยกโฟลเดอร์ตามชื่อ)
    ├── model/         # โมเดล LBPH ที่เทรนแล้ว
    └── logs/          # ภาพเหตุการณ์ + event_log.csv
```
